Runtime, privacy and supported limits
The pinned Pyodide 314.0.7 runtime downloads from jsDelivr; first load requires network access. Case data are processed in a local browser worker, not deliberately sent to a server. No browser storage or analytics is used. Keep downloaded files secure. Runtime files are separately licensed under MPL 2.0 and upstream third-party notices.
The core allows up to 1,000 records and coverage entries, but this workspace has a conservative 64 KiB original/working-package limit, 768 KiB complete envelope limit, 100 history entries and 2 MiB worker-request limit including escaping/metadata. Whichever limit is reached first applies. Larger cases require a different reviewed workflow; do not discard material evidence to fit.
